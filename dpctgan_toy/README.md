# Fabricated-data DP-CTGAN-style prototype

This is an isolated experimental prototype. It reads only `fabricated_data.csv`,
which is generated by `generate_fabricated_data.py`; it contains no project-data
paths or readers. It does not modify the existing preprocessing pipeline.

## Run

```powershell
python dpctgan_toy/generate_fabricated_data.py
python dpctgan_toy/train_dpctgan_toy.py
```

The scripts use the Opacus 1.6.0 package installed into `dpctgan_toy/.deps` and
the already installed CPU PyTorch. The training script validates those versions.
The generator outputs continuous values through fixed-bound `tanh` mappings,
and categorical values through a fixed smoking-history vocabulary plus a
binary target. It learns no category frequencies or preprocessing statistics.

The discriminator's real-record loss is updated through Opacus DP-SGD with
Poisson subsampling, per-record clipping, Gaussian noise, and an RDP accountant.
Fake-only discriminator updates and generator updates use generated rows and
the privatized discriminator state, so they are post-processing. This is a
minimal CTGAN-style toy design, not a reproduction of the medical DP-CTGAN
paper's architecture.

`secure_mode=False` is used because this is a CPU-only toy experiment. Fabricated
data, initialization, and latent vectors use fixed seeds; Opacus DP-noise draws
are deliberately not manually seeded, but use PyTorch's non-cryptographic RNG.
The accountant output is recorded, but the run is marked **PARTIALLY VERIFIED**
and is not suitable for real patient data or a production privacy claim. The
privacy unit is one fabricated row; there is no patient-level claim.
