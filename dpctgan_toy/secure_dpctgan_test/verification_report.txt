Compatibility assessment
------------------------
The official torchcsprng compatibility documentation lists Python 3.6-3.9
and the PyTorch 1.8.0/CSPRNG 0.2.0 combination. Opacus 1.6.0 requires
PyTorch >=2.6.0. Thus the current Python 3.10/PyTorch 2.6 environment has no
documented torchcsprng compatibility. An upstream source build may work, but
this has not been demonstrated and must not be treated as compatible merely
because package installation succeeds.

The documented legacy overlap worth testing in a disposable environment is
Python 3.9 + PyTorch 1.8.0 + torchcsprng 0.2.0 + an Opacus release whose
official compatibility table allows PyTorch 1.8 (Opacus 1.2 release notes
list PyTorch 1.8+). This is a candidate only: it is an old stack, the current
runner API has not been tested against it, and no secure mode, RNG identity,
training, or accounting comparison has been verified on it.

Candidate training configuration from the current fail-closed runner:
  noise multiplier 1.2
  clipping norm 1.0
  expected Poisson sample rate 0.125 (500 rows, base loader length 8)
  maximum planned private steps 64 (8 epochs x 8 sampler draws)

The actual step count must be measured from a run; Poisson batches can be
empty, and the runner skips empty batches. No epsilon is reported for this

its sampling RNG was seeded and secure mode was disabled.
